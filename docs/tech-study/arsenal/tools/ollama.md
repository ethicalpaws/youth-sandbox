📋 常用命令速查
| 命令 | 功能 |
|------|------|
| `ollama run <模型名>` | 运行/下载模型并进入对话 |
| `ollama pull <模型名>` | 仅下载模型，不启动 |
| `ollama list` | 查看本地已下载的模型列表 |
| `ollama ps` | 查看正在运行的模型 |
| `ollama rm <模型名>` | 删除本地模型 |
| `ollama serve` | 启动 Ollama 服务（通常后台自动运行） |
| `ollama launch <智能体> --model <模型名>` | 启动该智能体并调用该模型 |
