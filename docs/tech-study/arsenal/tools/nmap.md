# Nmap（Network Mapper）
>渗透测试和网络管理中最核心的侦察工具。它的核心能力是主机发现、端口扫描、服务与版本识别、操作系统探测，以及通过 NSE 脚本引擎进行漏洞检测。

🎯 核心扫描技术速查

| 扫描目标 | 常用命令 | 关键说明 |
|----------|----------|----------|
| 主机发现 | `nmap -sn 192.168.1.0/24` | 仅探测存活主机，不扫端口，适合内网资产盘点 |
| 端口扫描 | `nmap -p 80,443 192.168.1.1` | 默认扫描最常用的 1000 个 TCP 端口，`-p` 可指定范围 |
| 服务与版本 | `nmap -sV 192.168.1.1` | 探测开放端口上运行的具体软件及版本（如 OpenSSH 8.2） |
| 操作系统识别 | `sudo nmap -O 192.168.1.1` | 推测目标操作系统类型，通常需要 root 权限 |
| 综合扫描 | `nmap -A -T4 192.168.1.1` | 一次性启用版本探测、OS 识别、脚本扫描和路由追踪，`-T4` 加速 |

---

📖 常用选项精讲
1. 扫描速度与隐蔽性

-T4：常用的“敏捷”模式，在速度和准确性之间取得平衡。-T0 最慢但最隐蔽，-T5 最快但可能丢包。

-sS：TCP SYN 半开扫描，是默认扫描方式，速度快且相对隐蔽（不完成三次握手）。

2. 进阶探测

-sC 或 --script=default：运行默认的 NSE 脚本，快速检测常见漏洞或服务配置。

--script=vuln：专门调用漏洞检测类脚本，用于安全审计。

3. 结果输出

-oN result.txt：保存为普通文本格式，方便查看。

-oX result.xml：保存为 XML 格式，适合导入 Metasploit 等工具进一步利用。

🔍 结果解读要点
扫描结果中的端口状态直接决定了后续的攻击思路：

- open：端口开放，有服务监听，是主要攻击面。

- closed：端口关闭，但主机可达（能收到响应）。

- filtered：被防火墙或过滤器拦截，无法判断状态，说明存在防护。

- unfiltered：端口可访问，但无法确定开闭（多见于 ACK 扫描）。
