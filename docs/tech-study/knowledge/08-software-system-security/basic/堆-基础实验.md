# 堆基础实验
## 堆程序demo
```
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
    printf("=== 堆实验 ===\n");

    // 1. 申请两块 32 字节的内存
    char *a = malloc(32);
    char *b = malloc(32);

    printf("a 的地址: %p\n", a);
    printf("b 的地址: %p\n", b);

    // 2. 写入数据
    strcpy(a, "AAAA");
    strcpy(b, "BBBB");

    printf("\n释放 a 之前:\n");
    printf("a 的内容: %s\n", a);
    printf("b 的内容: %s\n", b);

    // 3. 释放 a
    free(a);

    // 4. 尝试通过 a 读取数据（这是非法的，但为了实验）
    printf("a 被释放后，尝试读取 a 的内容: %s\n", a); 

    // 5. 堆溢出攻击模拟
    memset(a, 'X', 60); // 写入 60 字节的 'X'，超过了 a 原本的 32 字节大小

    // 6. 查看 b 是否受到了影响
    printf("现在 b 的内容: %s\n", b); 
    // 如果 b 的内容变成了 "XXXX..." 说明堆溢出成功覆盖了 b

    return 0;
}
```

## 溢出程序demo
>如果我们精心构造溢出数据，将chunk b 的fd字段覆盖为指定地址就可以达到劫持fd指针的目的

![](堆-基础实验/2026-10-12-19-17-55.png)


```
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int main() {
    printf("=== 最简堆溢出 Demo ===\n");

    // 1. 申请两块 32 字节的堆内存
    char *a = malloc(32);
    char *b = malloc(32);

    // 2. 向 a 和 b 写入初始数据
    strcpy(a, "AAAA");
    strcpy(b, "BBBB");

    // 3. 释放 a和b，但不清空指针（UAF漏洞）
    free(a);
    free(b);
    // 4. 通过 a 写入超长数据，覆盖 b 的头部
    printf("[!] 请输入超长字符串（输入超过 40 字节的数据）:\n");

    char input[256];
    fgets(input, sizeof(input), stdin);

    // 去掉换行符
    input[strcspn(input, "\n")] = '\0';

    // 将输入写入已释放的 a，溢出覆盖 b
    strcpy(a, input);

    // 5. 查看 b 的头部（通过指针偏移）
    unsigned int *b_size = (unsigned int *)(b - 4);
    printf("b 的 size 字段 = 0x%08x\n", *b_size);

    // 6. 再次将b分配出去，此时fastbin的fd应该被劫持
    malloc(32);

    // 7. 再次分配chunk程序应该会崩溃
    malloc(32);

    return 0;
}
```
