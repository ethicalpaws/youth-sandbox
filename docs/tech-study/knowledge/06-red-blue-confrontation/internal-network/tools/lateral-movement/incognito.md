# incognito
>就像一把“万能钥匙”。当攻下一台服务器后，即使还没有拿到某个域管理员的密码，只要这个域管理员在这台机器上登录过，Incognito 就能找到他留下的“身份凭证”（令牌），并让你瞬间“变成”他，直接继承其最高权限

## 核心原理：令牌就是“临时钥匙”
Windows 中的 访问令牌（Access Token） 类似于网页中的 Cookie，是用户在登录系统或访问网络资源时，系统为其生成的临时身份凭证。只要用户（如域管理员）登录过一台机器，系统就会在内存中留下他的令牌。

这意味着，攻击者根本不需要破解密码或哈希，只要找到并盗用这个令牌，就能直接以该用户的身份进行任意操作

## 主要用途：内网渗透的“加速器”
在实战中，Incognito 主要用于以下场景：

- **横向移动与提权**：当你通过漏洞拿到一个普通权限的 Shell 时，如果发现机器内存中存有域管理员的令牌，就可以利用 Incognito 伪装成域管理员。这比本地提权到 SYSTEM 然后抓取 Hash 更直接。

- **信息收集与资源访问**：通过模拟其他用户的身份，可以访问原本受限的共享文件、数据库或远程系统，拓宽攻击路径


## 关键提醒

**权限要求**：通常需要先拥有 SYSTEM 级别权限（或者具备 SeDebugPrivilege 特权），才能成功窃取其他用户的令牌。

**令牌生命周期**：令牌会一直存在于内存中，直到机器重启或用户注销，这为攻击者提供了充足的时间窗口。

**工具形态**：Incognito 原本是一个独立工具，后来被集成进 Metasploit 和 Meterpreter 中。在实战中，既可以在 Meterpreter 里用 use incognito，也可以直接上传独立的 incognito.exe 执行。
