### 信息收集

- **对192.168.111.100主机进行端口扫描**

    ```
    nmap -sS -Pn --min-rate 1000 -p- 192.168.111.20    
    ``` 
    ![](red-team1/2026-10-22-00-24-52.png)

    80端口开放http服务，可能存在web漏洞
    445端口开放smb服务，可能存在永恒之蓝漏洞
    3306端口开放mysql服务，可能存在空口令/弱口令连接漏洞
